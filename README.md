# boilr-boilr-doc

> Boilr template to a document boilr template (so meta!).

> **Retired:** boilr templates predate AI coding tools and no longer make sense. This repository is archived read-only and will receive no further updates.

---

## Purpose
Template to document [boilr](https://github.com/tmrts/boilr) templates.

Creates the following files:

```
.
├── Makefile
└── docs
    ├── author.md
    ├── boilr-installation.md
    ├── boilr-purpose.md
    ├── boilr-usage.md
    ├── contributing.md
    └── related.md
```
